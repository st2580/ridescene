# RideScene

실내 자전거(스마트 트레이너·롤러) 훈련용 웹앱 시제품입니다.

- 훈련 프로그램과 FTP 선택, 배경 영상(기본 샘플, 내 영상 파일, 영상 주소, 지역별 실시간 도로 CCTV) 선택
- 위쪽 얇은 HUD 하나만 표시 (구간, 목표/실제 파워, 케이던스, 심박, 남은 시간, 다음 구간, 프로필)
- Web Bluetooth 센서 연결 (FTMS 트레이너, 파워미터, 심박계, 케이던스) 및 ERG 모드, 시뮬레이션 모드
- 훈련 구간이 바뀌면 배경 영상도 전환
- 라이딩 요약과 TCX 저장

안드로이드 Chrome 권장. 아이폰은 Bluefy 같은 Web Bluetooth 지원 브라우저가 필요합니다.
CCTV는 국가교통정보센터(its.go.kr) 오픈API 인증키를 앱에서 직접 입력해 사용합니다. 키는 브라우저에만 저장됩니다.
